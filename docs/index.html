🧠 AI शाळेच्या पद्धतीने शिका

मॉडेल खरोखर कसे चालतात (टोकन → embeddings → attention → RLHF & LoRA), मग ते नीट कसे वापरायचे (prompting, RAG, एजंट, diffusion) — प्रत्येक संकल्पना शाळेची गोष्ट, प्रत्येक धडा क्रमांकित आकृती आणि प्रत्यक्ष प्रयोगासह. प्रयोग शून्य-अवलंबित्व Python: GPU नाही, API key नाही, pip install नाही.
